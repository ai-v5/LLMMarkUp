# LLMMarkUp

<img src="assets/studio.png" width="96" alt="LLMMarkUp">

离线 Windows Markdown 工作台：左侧浏览目录，中间编辑源码，右侧实时预览。

## 功能

- 多文件标签：切换保留草稿、撤销与滚动位置；关闭标签、切换目录和退出保护相关未保存内容。
- 目录懒加载，支持创建根目录和子目录；右键目录可新建文件/子目录，右键文件可重命名、复制完整路径、移动或送入系统回收站。两处分隔条可拖拽调整。
- 最近文件/目录，重启恢复有效目录、标签与活动项；记住全局明暗与预览比例。
- 目录与编辑区共享明暗，预览独立明暗；编辑区与预览区各自支持触控板双指捏合或 Ctrl+滚轮缩放（50%～200%），只缩放所在栏的内容，不放大工具条或另一栏；支持编辑驱动的同步滚动。
- CodeMirror 编辑，markdown-it 预览，KaTeX 离线复杂公式，包括矩阵、多行对齐、分段、积分、求和；支持表格中的 `<br/>` 换行、任务列表和脚注。
- 保存保留 UTF-8 BOM 与 LF/CRLF，外部修改冲突时拒绝覆盖。

## 开发和构建

Windows x64，Node.js 22.12+：

```powershell
npm ci
npm start
npm test
npm run test:e2e
npm run dist
```

安装包位于 `outputs/installers/LLMMarkUp-0.6.0-Setup.exe`。安装后不需要 Python、Node 或本地 Web 服务。构建显式使用 `--publish never`，不会上传产物或创建 Release；当前安装包未签名。

本机开发交付使用 `npm run dist:local`：核验安装归属、正常请求关闭、原位安装、校验版本和应用包 hash 后重新打开。出现未保存提示时须由用户处理，脚本不会强杀。也可用 `powershell -File install-local.ps1 -InstallDirectory <目标目录> -Launch` 指定位置。首次安装默认当前用户 Programs 目录。

仅重跑安装版测试：

```powershell
$env:LLMMARKUP_TEST_EXE = '<安装目录>\LLMMarkUp.exe'
node --test tests/e2e.cjs
```

## 使用

`Ctrl+O` 打开目录，左上角“打开”含最近文件和目录；点击文件树打开标签。`Ctrl+S` 保存、`Ctrl+W` 关闭标签、`Ctrl+N` 新建 Markdown、`Ctrl+Shift+N` 新建目录、`Ctrl+F` 查找、`Ctrl+R` 重新读取磁盘。最近文件/目录各保留 12 项，最多同时打开 50 个标签。

全局配置位于 Electron 标准 `userData/studio-session.json`，仅保存打开记录、明暗和两栏缩放等界面状态，不保存未保存正文。首次从早期 MDPPT Studio 升级时，仅在新配置不存在的情况下读取既定旧配置，保留旧文件并迁移有效字段；新配置已存在时不再读取旧配置。Windows 安装身份沿用既有升级标识，界面、EXE、快捷方式和新安装目录使用 LLMMarkUp。

支持不超过 2 MiB 的 UTF-8 文档；混合换行、其他编码、目录越界和子路径中的符号链接/联接明确拒绝。公式支持 `$...$`、`\(...\)`、`$$...$$`、`\[...\]` 和 `math` 围栏，限于 KaTeX 支持集。


目录顶部采用单行小图标工具条与悬停提示，不显示“文件目录”标题；缩窄时按钮不换行，目录名过长省略，悬停可看完整路径。右键目录或目录栏空白处可新建 Markdown/子目录；右键文件可“移动到…”或“删除（移至回收站）…”。删除需确认，存在未保存内容时先选择保存/放弃/取消；系统回收站不可用时报告失败，不降级为永久删除。移动仅支持当前目录树内、同一文件系统中的目标目录，保留打开标签与未保存草稿，不覆盖同名文件，并更新最近记录。文件操作会核对磁盘版本；与不协作的外部程序在最终检查和文件系统操作间仍有极短竞争窗口，不声明多写入者事务保证。

编辑区比例显示在“可编辑”旁，点击百分比恢复 100%；预览保留比例下拉框。双指缩放采用 Chromium 的触控板捏合输入通道；未按 Ctrl 的双指滚动保留原有滚动行为。任务列表在预览中只读勾选状态，修改仍通过 Markdown 源码；脚注支持跳转与返回。

右键文件选择“重命名…”可修改文件名（包括仅修改大小写），需保留 `.md` 或 `.markdown` 扩展名。重命名同步更新标签、窗口标题和最近记录，保持活动标签、标签顺序、未保存内容、光标、滚动与撤销历史；磁盘正文不会被自动保存，仍通过 `Ctrl+S` 保存。目标同名、目标有已打开的标签或源文件发生外部修改时拒绝操作。“复制文件路径”将文件的完整本机路径写入系统剪贴板，不切换标签、不保存草稿，也可用于尚未打开的文件。
## 边界

应用无账号、遥测、模型 API、云同步或联网下载更新。仅将不带属性的 `<br>`、`<br/>`、`<br />`（不区分大小写）作为换行处理，其他文档 HTML 不执行；代码块、行内代码和转义文本中的写法保持原样。图片显示占位，外部链接不可导航，脚注链接仅在预览内部滚动；不允许文档发起网络请求或读取任意本地文件。未实现图片、Mermaid、崩溃草稿恢复及多人协作。

当前验证面向 Windows x64；自动化不能代替真人输入法、不同 Windows 版本、SmartScreen 和签名验证。配置迁移测试仅使用合成旧配置，不读取用户资料。
